Requirements

Windows
1: Please make sure TSDuck is installed and available in PATH
2: VLC Media Player installed at the default path
3: .NET Framework 4.0 or higher

Open T2MI_Extractor.sln in Visual Studio and build the solution.

Usage
1. Browse for the recorded T2MI stream file (e.g. tring_str_2.ts).
2. Click "Analyse TS" to read and display the T2MI tables from the stream.
3. Click "Extract Content" to de-encapsulate the T2MI stream, this will generate extr_tring_str_2.ts in the same directory.
4. Click "Play" to open and view the decoded video.
